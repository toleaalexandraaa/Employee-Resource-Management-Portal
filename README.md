
# Portal web pentru managementul resurselor unei firme

## Descrierea proiectului

Proiectul constă în dezvoltarea unei aplicații web pentru gestionarea centralizată a resurselor unei companii.

Aplicația urmărește eficientizarea proceselor administrative și facilitarea organizării informațiilor referitoare la angajați, clienți, proiecte și sarcini.

Soluția integrează o interfață web, un server backend și o bază de date relațională.

## Funcționalități principale

- Autentificarea și administrarea utilizatorilor.
- Gestionarea informațiilor despre angajați.
- Administrarea clienților și a proiectelor.
- Crearea și urmărirea sarcinilor.
- Organizarea activităților printr-o interfață de tip Kanban.
- Vizualizarea informațiilor prin intermediul unui dashboard.
- Gestionarea drepturilor de acces în funcție de rolurile utilizatorilor.

- TypeScript

- Angular Material

### Bază de date

- SQL

### Instrumente
- Visual Studio
- Visual Studio Code
- Git și GitHub

## Structura proiectului

- `company-resource-manager.client` – interfața web Angular.
- `company-resource-manager.Server` – logica aplicației și serviciile backend.
- `company-resource-manager.Tests` – componenta de testare.
- `company-resource-manager.slnx` – soluția Visual Studio.

## Proiectarea sistemului

În cadrul lucrării de licență au fost utilizate diagrame UML și BPMN pentru analiza și modelarea sistemului informatic.

Au fost abordate modelarea entităților, relațiile dintre componente și fluxurile principale ale aplicației.

## Testare

Proiectul include o componentă dedicată testării aplicației.

Structura permite verificarea comportamentului funcționalităților și identificarea eventualelor probleme.

## Date demonstrative

Datele utilizate pentru prezentarea și testarea aplicației sunt fictive și au exclusiv scop demonstrativ.

## Scopul proiectului

Proiectul a fost realizat pentru aplicarea practică a cunoștințelor dobândite în cadrul studiilor de licență, în domeniul dezvoltării aplicațiilor web, bazelor de date, analizei și proiectării sistemelor informatice.
